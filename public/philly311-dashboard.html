Fake console for Flick It Philly development

This is not a real government system. Run npm run 311-demo on a computer on the same Wi‑Fi as the phone. Set FLICK_311_DEMO_URL in the app’s .env to that machine’s LAN URL (shown in the server console), e.g. http://192.168.x.x:3110, then rebuild so submissions appear here. Marking Completed updates the resident’s app on the next sync.
